# Ranking data status

No official 2026 rankings are stored here yet.

When verified data sources are connected, publish one JSON per division in `data/official/`. Each team must include the source URL and checked date, and the calculated weighted merit score. The validator rejects missing data, inconsistent scores and duplicate ranks.

A passing schema check does **not** verify the accuracy or completeness of external sources. Team membership and game results must be separately reconciled before publication.
